# Core Figure Assets

This directory contains publication-layer figures for the English canonical edition.

## Rules

1. A figure must carry an analytical claim or an evidence boundary; decorative graphics are excluded.
2. Quantitative figures use only values already admitted into the report's fact / forecast / calculation architecture.
3. Every figure must state its source identity and the boundary that prevents denominator or time-state drift.
4. Conceptual figures are labeled as report frameworks and must not be read as empirical estimates.
5. SVG is the canonical editable format because it remains vector-native, diffable, and suitable for print / web export.
