## 出版层编辑标准

“完成合并”不是把多个 Markdown 文件拼起来，而必须同时满足：

1. 同一事实表只出现一次；
2. 同一机制只完整定义一次；
3. 深拆卷只贡献新增工程、数据、反方或证伪；
4. 宏观篇只吸收独有公式、BOM、跨卷推演与边界，不重复整段主论证；
5. 来源跟随事实进入出版章；
6. 对话流式短句在出版层重组为连续段落；
7. F/H/M/S/X 身份和 A/B/C/D 证据等级不能因合并丢失；
8. 研究层卷号不改，确保历史链接、issue、引用和双语镜像稳定。
