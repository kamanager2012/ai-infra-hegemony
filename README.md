## 主线

利润率垄断，不是份额垄断。预付款锁下一代。增量在高性能计算。残量给手机和电脑。中国栈三层不是一层，国内最多平行供给手机。云自研公开下一代仍走先进封装和高带宽内存，没有退回商品条。电是第三条配额。反垄断调查在，起诉不在。
