# Phase II · 通道判别检验 v0.1

> **状态：** 研究侧验证层；不属于冻结的 32 章正式报告，也不改变正式报告的 2026-08-28 证据截止日。  
> **目的：** 把 `19` §6 那句"下一份下游申报就能检验哪一通道在运作"变成**可执行的检验**——观察量、统计量、两个预测值、检验所需的分辨力，以及在数据到达之前就定死的裁决表。  
> **可复算产物：** `scripts/recompute_channel_discriminator.py` 读取 `data/channel-discriminator-inputs.json`。全部输出为 D 级报告侧计算。  
> **英文 canonical：** [22-channel-discrimination-test.md](22-channel-discrimination-test.md)（本文件为派生中文译本）

## 0. 归属契约 v0.1

本文件拥有：

- 区分两个传导通道的**观察量**，以及"它是一对已报告序列而非一份申报"这一陈述；
- **统计量**——下游环节链上收入对上游环节降幅的斜率——及其两个预测值；
- **分辨力曲面**：每一档披露粒度所需的最小上游降幅；
- **预登记裁决表**，含两条会**证伪层系当前主张**的结果。

本文件**不**拥有：传导链（`11` §2）、两个通道本身（`19` §6）、集中度锚点（`04C` §11B.5）、清算裁定（`01A`），以及任何逐环收入、覆盖或违约概率——后者本仓无处携带。它**不创造锚点**。唯一输入是 `04C` §11B.5 携带、`19` §2 已据以建曲面的那个已观察集中度。

**为什么需要新 owner。** `19` §6 说了三件事：两通道形状不同、已观察的 lockbox 是固定义务通道的证据、下一份下游申报"检验哪一通道在运作"。这是三种不同性质的陈述，而第三种并不能从前两种按字面推出：它没有点名要读哪个量、没有给出哪一个值算哪一通道的证据、也没有给阈值。它还漏掉了一个前提——见 §3。**一个无法以陈述的方式被证伪的检验不是检验**；而确立通道的那一层，不该同时提供裁决自身推断的规则。

## 1. 关于同一个斜率的两个主张

两通道不是两个不同量的模型，而是关于**同一个**量的两个主张：下游环节链上收入对上游环节降幅的斜率。

在 **A——比例渗透**下，中间义务是可变的，降幅连续到达，下游环节保留 `1 − c u`。在 **B——交易对手阶跃**下，义务是固定的、现金被围栏化，故下游环节在上游环节违约之前被隔离，之后一次性跨出大小为 `c` 的一步。

两者都只是单一已观察集中度 `c = 0.77` 的函数。不需要别的，也不主张别的。

## 2. 两个通道各自预测什么

保留率 = 下游环节链上收入占其此前水平的比例；上游降幅 = 上游环节自身已报告收入的降幅。B 列之所以是平的，是因为所示各行都还没有发生违约；总和降幅那一行代表的就是那个阶跃本身。

| 上游降幅 | A 保留率 | B 保留率 | 分离度 |
|---:|---:|---:|---:|
| 10% | 92.3% | 100.0% | 7.7% |
| 20% | 84.6% | 100.0% | 15.4% |
| 30% | 76.9% | 100.0% | 23.1% |
| 50% | 61.5% | 100.0% | 38.5% |
| 77% | 40.7% | 100.0% | 59.3% |
| 100% | 23.0% | 100.0% | 77.0% |

**分离度就是 `c u`，故下游序列永远是上游序列的一条衰减副本**——严格衰减，因为 `c < 1`。这就是该检验的天花板：下游环节的任何观察都不可能比链条的传导更敏感，而链条的传导率就是集中度比值本身。

保留率那一列就是 `19` §2 已经列出的那个函数。那一层算了它却没有给它命名：**它的表就是通道 A 的预测曲线**，参数是源头支付额的降幅；而通道 B 的曲线是 `19` 从未写在它旁边的那个常数 `100.0%`。两表在上游环节的已报告降幅**全部**可归因于该链时一致——那正是 §3 陈述的边界，而本表并不假设它成立。

## 3. 未被陈述的前提

上游降幅为零时，两个通道预测同一个观察：`100.0%`。**没有任何东西下降时，两个假设在观察上完全相同。**

所以一条平的下游序列只有在**配上一个已测量的上游降幅**时，才是对 B 的证据。单独读到它，它与两个通道都相容；因此 `19` §6 的"下一份下游申报就能检验哪一通道在运作"**不是一份申报的检验，而是两条序列的检验**：上游环节的已报告收入是前件，下游环节的链上收入是后件，任一单独都不决定任何事。

这是对 `19` 的**更正**而非补充，且它双向都切。一方面该检验比原先那句话所暗示的更**便宜**，而原话并未确立这一点：完全不需要源头经济性数据，因为前件在往里一环就能观察到。另一方面它更**弱**：前件必须是上游环节收入降幅中**可归因于链上的那一部分**，而该降幅中来自链外业务的部分有多少，实测斜率就被稀释多少。`19` §5 出于同样理由把上游集中度 `c₁` 带成一个旋钮；本检验直接读上游降幅，故不需要 `c₁`——这正是它便宜的原因，而这个替代正是它继承的边界。

## 4. 分辨力

两通道恰好相差 `c u`，所以只有当这个差超过披露能够分辨的量时，下游观察才能把两者分开。反解：`δ / c` 的上游降幅，是使下游序列移动超过一个分辨力 `δ` 的最小值。

| 分辨力（占下游环节链上收入） | 所需上游降幅 |
|---:|---:|
| 1% | 1.3% |
| 2% | 2.6% |
| 5% | 6.5% |
| 10% | 13.0% |
| 15% | 19.5% |

两列都是各自序列的比例，故此表不含任何收入水平、是无量纲的：读者代入自己手上那两条序列的实际报告粒度即可。

有两点值得写明，因为它们都与"披露越细越好"这一直觉相反。第一，**检验的地板由后件的粒度决定，而非前件**——精确的上游数字配上粗糙的下游数字是浪费。第二，因为 `c < 1`，**每一份上游降幅在变成下游信号之前都先被打折**，所以传导弱的链条同时也是难以检验的链条。决定冲击能走多远的那个集中度，同样决定了观察能看到多小的冲击。

## 5. 预登记裁决

四种结果，不是两种。该表在**此处**、在数据之前定死，使读法不能事后挑选。

| 观察到的斜率 | 裁决 | 它对层系做什么 |
|---|---|---|
| 接近 `0` | **B 在运作。** 固定义务在行为上与结构上一致。 | `19` §6 收敛为单一机制；该观察进 `01A` 作为一条融资族条目，绝不作为独立确认。 |
| 接近 `−0.770` | **A 在运作。** 尽管 lockbox 的结构如此，义务仍是可变的。 | `19` §6 的结构性推断被行为否定，必须从义务条款重新推导，而不是重新贴标签。 |
| 严格居中 | **两个通道都不是。** 机制是部分渗透。 | 二分法本身被观察证伪。必须重新推导，不得重新贴标签——并注意这正是"禁止取平均"那条边界规则本来会掩盖掉的结果。 |
| 比 `−0.770` 更陡 | **分母错了。** 移动下游环节收入的还有链以外的东西。 | 前件并不按 §3 要求的方式可归因于链，稀释边界才是首先要测的东西。 |

第三行就是本层存在的理由。`19` §9 禁止把两通道相加或取平均，那条规则对**模型**是对的；但如果世界返回一个居中的斜率，被违反的并不是那条禁令——**被违反的是"两通道互斥"这个假设**。一条阻止分析者把两个假设取平均的规则，不能同时阻止数据把两者都拒绝掉。

## 6. 什么会瓦解它

1. **中间环节的义务条款被披露**——租约是否 take-or-pay、期限、以及现金是否在合同上被围栏化——会使 B 成为合同问题而非推断问题，检验随之不必要。该检验是读者手上没有合同时才需要的东西。
2. **上游集中度 `c₁` 被披露**会使前件中可归因于链的份额可测，从而移除 §3 的稀释边界。
3. **逐环收入拆分被披露**会使两条序列都干净，斜率可直接读出，而不必透过边界推断。
4. **披露本身**会用序列的实际粒度取代 §4 的旋钮，把分辨力曲面变成一句关于**某一对**申报的话。

## 7. 边界规则

- **无新锚点。** 唯一输入是 `04C` §11B.5 携带的集中度；`04C` §11B.5A 的规则——不得由另一借款人的值推断本借款人的值以补全矩阵——原样适用。
- **两通道互斥，不是分层。** 它们是关于同一个斜率的两条假设。把它们取平均会得到一个不属于两者的斜率，更糟的是会让 §5 的第三种裁决**不可达**。
- **裁决表是预登记的。** 它在数据之前陈述，且不得在读过申报之后修改。一张能在观察到手后调整的表是描述，不是检验。
- **无逐环主张。** 本文件不陈述任何具名公司的收入、覆盖、余量或违约概率，也不对任何公司断言斜率。
- **无合成指数。** 保留率曲线、分离度列与分辨力曲面绝不可净额化为分数，也不可与多族信号相乘。
- **不切情景、不确认 S4、不给证据等级。** 本文件不能改变 `10` 的情景相关性，不能确认 S4，不能进入冻结章节。
- 任何输出被复用处，按 `04-research-transparency` 的等级体系，**D 级标注为强制**。

## 8. 整合

1. 当 `19` 的通道、`04C` 的集中度锚点或已观察序列变动时，重跑 `scripts/recompute_channel_discriminator.py`。
2. **补上 `19` §6 缺失的规则。** `19` 陈述了形状差异并点名了检验；本层定义观察量、统计量与裁决。`19` §6 与 §8.3 带一条回指，使在该处遇到该主张的读者不会只拿到一个跑不起来的检验。
3. `01A` 裁定：被确认的阶跃是一条融资族观察——记为若干族之一，绝不作为独立的 S4 确认，使用 `01A` 既有的状态词汇。
4. **提议的扩展（尚未落地）：** 一旦逐环收入拆分被披露，保留率序列即成为 `04C` §11B.7C 变现桥中的一项设施状态字段，§4 的分辨力旋钮由实际粒度取代。在此之前 `04C` 不变。
