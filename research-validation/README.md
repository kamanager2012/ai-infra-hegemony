# Phase II · Empirical Validation & Scenario Calibration

This directory is the **independent validation layer** created after the 32-chapter formal report was frozen. It is not part of the frozen publication text and does not change the formal report's **August 28, 2026 evidence cutoff**.

Its purpose is not to keep polishing the publication. It exists to test the report's highest-impact mechanisms that still require historical, causal, or prospective calibration.

**Canonical research language: English.** All Phase II analytical files are authored in English. Any Chinese version is a derived translation and must not create, remove, reorder, or redefine evidence identities, denominators, state labels, causal mechanisms, thresholds, or conclusions independently of the English canonical text.

## Work order

1. **P0-1 Historical Clearing Backtest** — test the five Chapter 24 clearing-signal families;
2. **P0-2 AI Demand Elasticity Calibration** — estimate empirical price/usage response using reproducible model-traffic data;
3. **P0-3 Verified Workflow Economics** — operationalize cost per verified workflow outcome and durable workflow ROI;
4. **P0-4 Macro-Financial Transmission** — connect rates, credit, equity support, project finance, and refinancing to the capital cycle;
5. **P1 Geopolitical Scenario Layer** — make Taiwan continuity, export controls, alliance structure, and China closure explicit state variables;
6. **P1 Conditional Timeline** — convert fixed-year language into condition → milestone → contrary-signal logic;
7. **P2 Downstream Empirical Chains** — maintain auditable Labor / Education / Physical-AI transmission chains;
8. **P1 Demand-Side Reflexivity** — support the formal S4 demand-side mechanism (Chapter 24 §7B et al.) with its research-side panels, clocks, and demand-side observables; the formal text is authoritative.
9. **P1 Capital-to-Cash Bridge** — perform the required-cash-versus-contracted-revenue division per GW-year from already-graded anchors, and maintain it as a reproducible artifact.
10. **P1 Cost-per-VSWO Break-Even Surface** — state the dimensionless conditions under which a claimed workflow effect survives the P0-3 closure identity.
11. **P1 Time-to-Power Energization Surface** — compute the announced → energized → utilized → revenue-bearing schedule as a conditional surface over published lead-time ranges, including the critical-path overlap credit.
12. **P1 Ramp-Period Funding Gap** — put the required-cash floor on the energization clock and compute the cumulative funding requirement, its peak, and the crossover.
13. **P1 Chain Concentration Amplification** — quantify how far an origin shock travels down a fixed-obligation financing chain, at what point each link breaches, and which channel is transmitting.
14. **P1 Demand-Side Composition & Incidence** — put the observed adoption rates on a common denominator, and show that the incidence question reduces to one ratio that bounds the demand effect rather than freeing it.
15. **P1 Frozen-Text Gate Status** — record which variables a frozen chapter names as required are now carried by the research panels, and state which of them cannot be observed before the outcome they describe.
16. **P1 Channel Discrimination Test** — turn the two-channel distinction into an executable test: the observable, the statistic and its two predicted values, the resolving power a disclosure needs, and the verdicts fixed before the data.

It is the only gate covering `research-validation/`: the research-layer numeric gate is scoped to the 96-file historical corpus and the publication gate to the 64 formal chapters, so before this the layer system had no regression test at all. Its core rule is that a registered headline number must appear in **its layer's script stdout, the English canonical, and the Chinese translation** — three sources that cannot drift apart silently. It additionally fails on a layer added without a registry entry or README wiring, a translation that stops tracking its canonical, an orphan or renamed layer file, a script that stops exiting 0, and a recompute script with no registry entry. Registry: `data/layer-consistency.json`. **Registers:** 9 layers, 8 versioned inputs, 8 recompute scripts, 45 headline tokens, 31 borrowed anchors, 38 table pairs, 1 stated derivation, 11 declared unaccounted values. When it fails it does not stop at naming the broken check: it prints an **affected-layer report** — which layers have to be re-run, their scripts, and the sections of their canonical that cite the anchor — and follows the dependency chain into layers that never cited the source themselves. A broken anchor in `04C` therefore names `15` (which publishes a value derived from it) *and* `18` (which reads that value from `15`) rather than only the layer whose registered literal disappeared. Two further checks carry coverage past the headline set: **table parity** (both editions carry the same tables, so the same quantities must appear in both — compared as multisets, no exception list needed) and **stated derivations** (a rule a layer states in prose is re-implemented by the gate and must reproduce the value the layer publishes; the register holds one, `16`'s productivity-to-time conversion, whose output `0.123` was previously entered by hand and produced by no computation). A third check covers what is left. **Unaccounted values** are the quantities in a layer's canonical that no script output, versioned input or registered token produces — the residue after every other source is credited. It is **enumerated in the register, with the reason each is legitimate** (worked arithmetic in a convention note, the percent rendering of a fraction the script prints, arithmetic on two printed values, a value quoted from an upstream layer, and one facility name that is not a quantity at all), and checked in both directions: a quantity that becomes unaccounted fails, and a declaration whose value is now produced fails as stale. The reason for declaring rather than exempting is that a rule relaxed until the residue passes is a rule that has been deleted; the reason the residue is only 13 values is that it was **measured before it was enforced**. Two of the values first listed there were ones their scripts computed and did not print; both have since left the list because the scripts now print them, which is the direction that check is meant to push. A fourth check covers the **public summary**: every quantity on the README's bullet for a layer must be one that layer produces — its tables, its registered tokens, or its script output, with a fraction also accepted as its percent. It is the check that would have caught the defect that motivated the residue check, because when three documents quoted `15`'s retired `2.51×` the README was one of them and nothing was watching it. It deliberately does **not** credit the layer's prose: prose is where retired values and worked examples legitimately live, and crediting it makes the rule vacuous rather than lenient — reverting the README to `2.51×` then produces an empty difference set. Credit-the-prose and credit-only-produced were both **measured before either was written**. It is itself tested by [`scripts/selftest-layer-consistency-gate.py`](../scripts/selftest-layer-consistency-gate.py): 44 cases run against a throwaway copy of the tree, 41 of which must make a named check fire and 3 of which must stay green, so neither a silent gap nor an over-eager gate passes unnoticed. The self-test is committed rather than run once because this repository has no CI: a gate whose failure behaviour was verified in a shell that no longer exists is a gate nobody can re-verify.

  Two further checks carry the coverage past the registered headline set, which is deliberately narrow.

**Table parity.** Headline tokens are a handful per layer; the tables are where most of a layer's numbers actually live. Both editions carry the same tables, so the same quantities must appear in both, compared as multisets and matched table-by-table in document order. This needs no exception list, because a translation is not permitted to move a number at all — the only thing that has to be excluded is dates, since an edition writing "April-2026" where the other writes "2026-04" is not a numeric disagreement. It is what makes "a translation tracks its canonical" true at every table pair rather than at the handful of registered tokens — both counts are stated in the register's size line under Current status, which is the only place either is allowed to live. Its first run covered the tables it was written for and no exemptions were needed.

**Stated derivations.** A layer may state an arithmetic rule in prose and apply it to a published value. The register names the rule, and the gate re-implements it — independently of the layer's own script — and requires it to reproduce the published result. Two implementations agreeing is the check. This exists because of how the class behaved: `16` states that a reported productivity gain is not a time saving (`s = 1 - 1/(1+g)`, so +14% gives `s = 0.123` and not `0.14`), and that rule lived only in prose while the published `0.123` was entered by hand and produced by no computation. A rule stated only in prose cannot fail. The register now holds one derivation, and it is stated as one rather than as a survey.

It also checks **back-references**, which is the one dependency direction the registry itself cannot supply. A new layer is one-directional by default: its §0 states which layer continues to own the underlying facts, and nothing makes that upstream file point back — so a reader who reaches the authority first finds a bridge listed as future work when it already exists. Every such edge registered so far is closed: `15` in `04C` §11B.7C (whose "future updates should connect" list named exactly what `15`/`17`/`18` later connected), `16` in `03` §17.9 (whose stop rule needed to say that the dimensionless break-even form lives outside it), `19` in `11` §2 (which draws the propagation chain and owns it but computes nothing between its links), `20` in `14` §9 (which owns the rates `20` composes), and `22` in `19` §6 (which names a test — "the next downstream filing tests which channel is operating" — while supplying no observable, no statistic and no threshold, so a reader who meets the claim at the authority has no test to run, and no statement that one exists). The registry field is named `upstream_must_acknowledge` and is an obligation rather than an inventory — dependencies whose upstream already points back are deliberately not listed.

  And it checks **borrowed anchors**, which makes "no new numeric identities" executable rather than a rule a reader has to take on trust. Each borrowed anchor is registered with the document it must still be findable in, across upstream panels (`04C`/`04D`/`03`/`11`/`14`/`15`/`17`) and the **frozen chapters** (`Ch07` Table 7.2 for `17`'s lead-time streams, `Ch13` for `15`'s commitment anchor). This is the guarantee `18`'s script already implements for `15`'s table, generalised: if an upstream layer or a frozen chapter moves a value, the check fails loudly instead of letting the derived layer keep publishing the old one. Anchors borrowed from frozen chapters are searched in **both editions** — the two are the same fact in two languages, so either satisfies — and that is also why this is the strongest form of the check available: the frozen text is the fixed point the research side is not permitted to move.

- **Frozen-Text Gate Status:** **v0.1.** New research-side register recording the coverage status of a test a **frozen** chapter sets for itself — the one thing the layer system had no home for, since it reads the frozen text and cannot write to it. Ch23 §1B is the corpus's only enumerated such test, and it gates the report's most rhetorically loaded comparison: it names **eight contract-level variables** a defensible telecom-bubble / 2008-securitization replay claim would require, and states that without them "the analogy remains a research heuristic, not a formal report conclusion." Status: **4 of 8 carried** (`04C` §11B.5/§11B.5C; `11` §2A; `04D`), **2 partly observable** (leverage/LTV and senior-junior loss allocation — both have the instrument half and lack the valuation half, so the quantity cannot be formed), **2 not yet observed**. Those last two are the layer's result: **default / restructuring behavior** and **secondary-market liquidity of the underlying assets** are *outcomes rather than states*, so no disclosure can supply them before the event and the test has a **floor that further reporting cannot lift**. That is stronger than "the evidence is incomplete" and it does **not** make the analogy wrong — it makes it unpromotable by any amount of future disclosure, which is where the chapter's own caution and the structural bound agree. The register is one gate stated as one gate, not a survey. Reproducible via `research-validation/scripts/recompute_frozen_gate_status.py`; no new numeric identities; no formal-text change; the reopen gate is unchanged.

The **first** repair is the script: if the layer computes the value and renders it away — a rounded cell, a shortfall where the level is what the prose discusses — print it. The **second** repair is a declaration under `unaccounted` with the reason, and that is for values nothing should produce: worked arithmetic in a note, the percent rendering of a printed fraction, arithmetic on two printed values, a value quoted from an upstream layer, or an extractor false positive. Do not fix it by loosening the extractor or by dropping the value from the document: a declaration is a sentence on the record that a reader can check, and the check fails both when a new value goes unaccounted and when a declaration outlives its reason. Adding a registered derivation, or a layer, changes the register's size line in the same commit. When you move a value a layer publishes, grep the **README's** bullet for that layer in the same commit: the summary may state only values the layer produces, and it is the surface a reader meets first, so a stale number there is the most visible kind. If the summary needs to keep stating the old value — because the change is itself the point, as in `15`'s convention note — then the value belongs in the layer's prose and out of the summary.
