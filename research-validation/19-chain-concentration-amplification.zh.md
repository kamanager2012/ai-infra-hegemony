## 0. 归属契约 v0.1

本文件拥有：

- 沿融资链的**渗透乘数**（由已观察集中度导出）及其**残值**；
- 在已观察契约下限上的**所需冗余**与**可吸收降幅**曲面；
- **两个传导通道**——比例渗透与交易对手阶跃——二者的可计算差异，以及区分哪一通道在运作的那个观察；
- 判定"哪一环先感到冲击"的**排序规则**，以及置于该规则之下的已观察结构性事实。

本文件**不**拥有：融资分类与因果图（`11`）、传导链本身（属 `11` §2）、借款人/设施状态（`04C`）、支持激活（`04D`）、所需现金下限与通电时间表（`15`/`17`）、清算裁定（`01A`）。它**不创造锚点**——每个输入都读自 `11` 与 `04C`。

**为什么需要新 owner。** `11` §2 画出了传导链，§7 点出了判别变量——*独立现金生成 对 固定资本义务*——但 `11` 是分类层，并明确拒绝给它一个数字。`04C` §11B.7C 把"DSCR / 利息覆盖"列入未来桥梁应连接的字段，§11B.7D 定义了设施何时升级为压力状态，却没有定义冲击要走多远才能到达那里。**两者都没有拥有环与环之间的传导算术**，而正是这个算术把两个已观察的集中度比值变成"谁先断"的陈述。

## 1. 已观察到的链

`11` §2 给出链，`04C` §11B.5 给出每一环的义务：

```text
锚定方 / 终端客户经济性
  → CoreWeave 合同经济性
  → CoreWeave 偿债              ~US$25.1B 债务；2026 年余期 US$6.1B、2027 年 US$5.7B 到期
  → Core Scientific 托管现金流   CoreWeave ≈ 2026H1 收入的 77%
  → Core Scientific 偿债        US$4.4B 债务；2026–2028 无到期，2029 年 US$649.8M
```

三个已观察事实框定了下文一切：

1. **集中度为 0.77**——本仓所有位置唯一携带的已观察环间比值；
2. **上游义务无上限且迫近**——2026 年余期有 US$6.1B 本金到期；
3. **下游义务有界且遥远，其现金被围栏化**——2026–2028 无本金到期，且 CoreWeave 合同收入进一个**支持该债务的 lockbox**。

## 2. 渗透与残值

设 `x` 为源头向直接交易对手支付额的下降比例，`c` 为下游环节来自该链的收入集中度。比例渗透下：

```text
收入_后  = 收入_前 x (1 - c x)
覆盖_后  = 覆盖_前 x (1 - c x)
```

在已观察的 `c = 0.77` 下：

| 源头降幅 | 保留收入 | 覆盖乘数 |
|---:|---:|---:|
| 25% | 80.8% | 0.807× |
| 50% | 61.5% | 0.615× |
| 100% | **23.0%** | **0.230×** |

**集中度比值同时是放大因子与残值。** 在 `c = 0.77` 下，源头完全停摆仍给下游环节留下 23% 的收入，因为那 23% 来自别处。这一个数字是集中度最能说明的事，也是"集中度统计本身不是困境统计"的原因。

## 3. 所需冗余

把恒等式反解：要在降幅 `x` 之后恰好坐在下限 `F` 上，一环必须已持有 `F / (1 − c x)`。

| 源头降幅 | 1.15× 契约下限所需 | 1.00× 纯利息覆盖所需 |
|---:|---:|---:|
| 5% | 1.196× | 1.040× |
| 10% | 1.246× | 1.083× |
| 20% | 1.359× | 1.182× |
| 30% | 1.495× | 1.300× |
| 50% | 1.870× | 1.626× |
| **100%** | **5.000×** | 4.348× |

**源头完全停摆需要 5.00× 的当前覆盖**——恰好是 `1.15 / 0.23`。持有低于其偿债额五倍的任何一环，在这个集中度下都扛不住交易对手归零。

## 4. 可吸收降幅

同一结果从另一侧读——一环能活下来的最大源头降幅：

| 事前覆盖 | 在 1.15× 契约下限的可吸收降幅 |
|---:|---:|
| 1.20× | 5.4% |
| 1.30× | 15.0% |
| 1.50× | 30.3% |
| 1.75× | 44.5% |
| 2.00× | 55.2% |

**已坐在契约下限上的一环可吸收 0%**，这很平凡——不平凡的是紧随其后的事实：**吃掉大部分冲击预算的是契约下限，不是集中度。** 在 1.50× 覆盖下，该环在失去利息覆盖前可吸收 43.3% 的降幅，但在违反契约前只能吸收 **30.3%**。1.15× 的下限正是把 1.30× 处的 30% 冲击预算压成 15%、并在下限处压成零的那个东西。

这是对报告一句定性断言的定量陈述：**契约是放大器，不是护栏。**

## 5. 链的深度——冲击向外衰减

每多一环，抵达的冲击就乘以该环自身的集中度，因此累计渗透是乘积。上游环节自身的集中度**在此处携带的行中未披露**，作为旋钮进入：

| 上游 `c₁` | 累计 | 停摆时保留 | 所需覆盖 |
|---:|---:|---:|---:|
| 0.50 | 0.385 | 61.5% | 1.870× |
| 0.77 | 0.593 | 40.7% | 2.825× |
| 0.90 | 0.693 | 30.7% | 3.746× |

**冲击随向外传导而衰减。** 离源头最近的那一环吸收源头冲击的最大份额；单凭位置预测后果是反的。这值得写下来，因为直觉读法——最远的一环最暴露——在本模型中是错的。

## 6. 两个传导通道

上述比例模型是两个机制之一，而已观察到的结构会在二者之间做选择。

**通道 A——比例渗透。** 当中间义务是可变的（收入分成、成本加成、可重新谈判，或中间环节靠压缩自身毛利吸收）时适用。源头冲击以 `c x` 连续抵达。

**通道 B——交易对手阶跃。** 当中间义务是固定的（take-or-pay 租约，或现金被合同围栏化）时适用。下游环节被**隔离**，直到上游环节自身的覆盖违约，然后一次性承受大小为 `c` 的阶跃。

| 上游在 `x*` 违约 | A 在 `x*` 的损害 | B 在 `x*` 的损害 | 阶跃比 |
|---:|---:|---:|---:|
| 20% | 0.154 | 0.770 | **5.00×** |
| 30% | 0.231 | 0.770 | 3.33× |
| 50% | 0.385 | 0.770 | 2.00× |
| 77% | 0.593 | 0.770 | 1.30× |

**两个通道的差别在形状，不在期望水平：A 漂移，B 阶跃。** 而 B 在关键时刻更糟——若上游在源头降幅 30% 处违约，B 一次性施加完整的 0.77，而 A 只会施加 0.231，**瞬时冲击大 3.33 倍**。

**已观察到的结构指向通道 B。** `04C` §11B.5 记载 CoreWeave 合同收入**进一个支持 Core Scientific 债务的 lockbox**——即中间义务是固定的、现金被围栏化。因此在通道 B 下，决定性的量**不是** Core Scientific 的冗余。Core Scientific 在上游违约之前是被隔离的；决定下游命运的是 **CoreWeave 的违约点**。CoreWeave 的覆盖**本仓未携带**，所以本层止步于规则，不断言该数字。

**区分两个通道的特征可直接观察，而且便宜。** 通道 A 下，下游环节来自该链的收入按比例跟随源头；通道 B 下，它保持平坦、然后以阶跃移动。**下一份 Core Scientific 申报即检验哪一通道在运作**——这是本层最便宜的一次检验。

**该检验现在有了可运行的形式，并带一处更正。** 观察量、关联两条序列的统计量、每个通道下它的预测值、分离所需的披露粒度，以及在数据**之前**（而非之后）定死的裁决，均由 `22` 拥有。该层还记录了一个本节未陈述的前提：**上游降幅为零时，两个通道预测同一个观察**，所以没有已测量的上游降幅，平坦的下游序列不决定任何事。因此该检验是**两条序列，而不是一份申报**；上面的表述在 `22` 处被更正，而不是留在这里。

## 7. 哪一环先感到

`11` §7 的判别变量是*独立现金生成 对 固定资本义务*。把已算出的部件置于已观察的结构性事实之上：

```text
某一环的压力  =  累计集中度
                 x 该窗口内到期的义务
                 / (高于其自身下限的冗余 x 收入)
```

每一环的收入与覆盖在本仓未携带，因此**规则被陈述，不主张任何排序**。可以置于其下的是已观察事实，而它指向一个不显然的位置：

| | Core Scientific（77% 集中） | CoreWeave（墙最重） |
|---|---|---|
| 窗口内到期本金 | **2026–2028 年 US$0.0B**；2029 年 US$649.8M | **2026 年余期 US$6.1B**、2027 年 US$5.7B，总债务 US$25.1B |
| 已承诺未提取流动性 | 未携带 | 2026-06-30 时 US$10.0B |
| 未提取 / 2026 墙 | — | **1.64×** |
| 未提取 / 2026+2027 墙 | — | **0.85×** |
| 结构 | CoreWeave 收入进 lockbox；无浮动利率债务 | 多个 SPV 结构；DDTL 4.0 基本无追索 |
| 混合报告利息 | 3.70%（含一只 0% 票息可转债） | 6.80% |

**集中度与迫近性指向不同的环节。** 集中度更高的那一环墙更缓、现金被围栏、混合债务成本更低。面对迫近到期墙的那一环，恰是源头直接付款的那一环——而且**其 2027 年到期墙不被已承诺流动性覆盖**（0.85×），因此必须再融资，这使再融资可得性成为从源头经济性传导到下游环节的通道。

两条保留，均予声明而非抹平：US$6.1B 是 **2026-03-31** 时点，而 US$10.0B 可用额是 **2026-06-30** 时点，故 1.64×/0.85× 是跨日期的边界比较，不是时点覆盖陈述；3.70% 的混合利率含一只 0% 票息可转债，因此与 6.80% 不是同口径的成本比较。

## 8. 什么会击穿它

1. **披露逐环收入与覆盖**——将以算出的排序取代排序规则。
2. **披露 CoreWeave 自身客户集中度**——将移除 `c₁` 旋钮，使链的深度按观察复合。
3. **下一份下游申报**——将直接指认通道 A 或 B，把 §6 塌缩为单一机制。
4. **披露任一环的固定费用覆盖或 DSCR**——将使 §3 的所需冗余曲面可与真实数字而非下限约定对照检验。

## 9. 边界规则

- **无新锚点、不在借款人之间互推。** 每个输入都读自 `11` / `04C`；`04C` §11B.5A 的规则——不得为补齐矩阵而从另一借款人推断数值——原样适用。
- **集中度比值不是困境度量。** 在 `c = 0.77` 下该环在源头完全停摆时仍保留 23% 收入；集中度本身不说明这够不够。
- **两个通道是互斥选项，不是层。** 不得相加、平均、或用它们夹出一个区间。哪个在运作是经验问题，由下一份申报回答。
- **不对任何一环作主张。** 此处不陈述任何具名公司的覆盖、冗余或违约概率。
- **禁止合成指数。** 渗透乘数、所需冗余曲面与义务时间表绝不可净额化为分数，也绝不可相乘进任何多族信号。
- **不切换情景、不确认 S4、不创造证据等级。** 它不能改变 `10` 的情景相关性、不能确认 S4、不能进入冻结章节。
- **D 级标签是强制的**：凡复用任何输出，按 `04-research-transparency` 的层级必须携带该标签。

## 10. 整合

1. `11` 的链、`04C` 的集中度锚点、或任一环的义务时间表变动时，重跑 `scripts/recompute_chain_amplification.py`。
2. **供给 `18` 的终端环节。** `18` 计算合同支持设施的所需现金曲线；本层计算源头冲击如何抵达持有该合同的设施。组合二者是**衔接**，同一条禁令适用：不得由 `19` 与 `18` 构建任何合成指数。
3. **拟议扩展（尚未应用）：** 一旦逐环收入与覆盖被披露，`04C` §11B.7C 的变现桥梁可以把可吸收降幅作为设施状态字段携带。在此之前 `04C` 不变。
4. `01A` 裁定：下游环节链收入的阶跃变化将构成融资族的一项观察——作为若干族之一记录，绝不作为独立的 S4 确认。
