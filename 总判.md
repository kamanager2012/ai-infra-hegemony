## 一、当前总判断

截至 2026 年 8 月，AI infrastructure 最重要的产业变化已经从“GPU 需求快速增长”上移到：

> **system stack、scarce capacity、infrastructure coordination、capital formation 与 workload monetization 的复合竞争。**

当前事实组合最接近：

> **S2 — Baseline Concentration**

即：

- 领先 system platform 仍拥有很强 seller-side economics；
- hyperscaler custom systems 已形成真实替代路线；
- HBM、advanced packaging、power / LPS 等关键层仍存在明显物理约束；
- China parallel stack 持续扩大，但 frontier-system closure 仍需逐层验证；
- 高强度资本扩张仍在继续，尚不足以确认 S4 Capital Hard Landing；
- 资本结构开始从 hyperscaler corporate CapEx 扩展到 third-party infrastructure capital、Anchor Buyer commitments 与 seller-assisted financing。

## 二、竞争单位已经从 Chip 上移到 System Stack

真正需要比较的不再是：

> GPU vs ASIC

而是：

> **accelerator + memory + interconnect + compiler/runtime + rack/pod + data center + power + production workload**

NVIDIA 当前优势来自完整 system coordination，而不是拥有所有物理供应。

Google TPU、AWS Trainium、Microsoft Maia、Meta MTIA、AMD Instinct / ROCm 等路线已经证明，竞争者也在向完整 system stack 发展。

长期判断的关键变量是：

- production workload share；
- migration cost；
- utilization；
- system TCO；
- external adoption；
- upstream supply access。

## 三、AI 正在改变半导体“下一美元资本投向哪里”

本报告使用 **AI Resource Gravity** 与 **Two-Speed Semiconductor Economy** 描述这一变化。

核心机制是：

> **high-value AI/server demand → higher expected return → product-mix / capacity-allocation shift → more capital toward AI/HPC → residual supply conditions change for other markets**

这里不再使用一个综合“新增资源捕获率”把 advanced logic、HBM、advanced packaging、networking 与 power 压成单一百分比。

不同物理层必须分别观察：

- qualified supplier；
- lead time；
- allocation fulfillment；
- long-term agreement / prepayment；
- customer concentration；
- delivery schedule；
- supply elasticity；
- buyer credit quality。

## 四、HBM、Advanced Packaging 与 Power 是不同物理池

### HBM

Micron 一手披露，在 same technology node / same number of bits 条件下，HBM3E 约需要 DDR5 **3× wafer supply**。

这是一项 manufacturing-input trade ratio，不是：

- 价格倍数；
- market share；
- 所有 HBM 世代永久固定常数。

### Advanced Packaging

TSMC 已公开确认 advanced-packaging tightness 会限制 customer growth。

但：

> **customer demand share ≠ actual allocation share**

TrendForce 对 NVIDIA 2025 CoWoS demand >60% 的估计属于机构研究，不是 TSMC customer-allocation disclosure。

### Power / LPS

Power 分析必须区分：

> **Announced → Contracted / Secured → Permitted → Construction / Transition → Energized → Utilized**

2026-08-17 的 PORTS-Pike 项目进一步说明，AI infrastructure 的前置约束正在从单纯 MW/GW 上移到 **land + power + shell（LPS）**。

初始 **4.25 IT-GW** 是 design capacity，不是当前 energized load；IT-GW 也不能与 generation GW 或 PPA GW 机械相加。

## 六、模型公司已经成为 Anchor Compute Buyer

OpenAI、Anthropic 等大型 model company 已经不只是 cloud tenant。

其长期需求可以形成：

> **long-duration model demand → revenue visibility → financing certainty → earlier infrastructure buildout → earlier resource reservation**

2026 年进一步出现：

- Stargate >10 GW secured-capacity milestone；
- Michigan 1 GW campus construction；
- Anthropic / AWS >US$100B ten-year commitment、up to 5 GW；
- PORTS-Pike 的 LPS + credit-support 结构。

这说明 model demand、system platform、infrastructure developer 与 capital provider 正在更紧密耦合。

## 七、资本分析新增一个关键变量：Financing Reflexivity

2026 年的最新结构已经不能只用“hyperscaler CapEx”解释。

NVIDIA 已公开披露：

- 与大型长期资本提供方建立 compute financing platforms，目标是随时间动员 **>US$500B third-party capital**；
- 在 PORTS-Pike 项目提供 LPS credit support；
- 对 frontier AI labs 进行大规模 equity investment，并披露 selective credit enhancement。

因此，未来必须区分：

1. independently financed end demand；
2. long-duration Anchor Buyer commitments；
3. third-party infrastructure capital；
4. supplier equity / credit support。

supplier-assisted financing 不等于需求虚假。

但如果：

- utilization 下降；
- monetization 走弱；
- refinancing 越来越依赖 seller support；

则 forward demand signal 的独立性应下调，S4 risk 上升。

中国 parallel stack 不能用一个“国产化率”概括。

- advanced logic；
- HBM-class memory；
- advanced packaging；
- high-speed interconnect；
- compiler/runtime；
- production workload；
- system utilization；
- power；
- upstream equipment / materials continuity。

## 九、未来不是一个单点预测

本报告保留四类并列状态：

- **S1 — Competitive Expansion**
- **S2 — Baseline Concentration**
- **S3 — Resource Hegemony**
- **S4 — Capital Hard Landing**

不再使用未经可靠 allocation data 支持的固定 40%–80% 跨层“资源捕获率”定义情景。

决定未来状态的核心变量包括：

- AI workload demand；
- supply elasticity；
- layer-specific quantity assurance；
- system substitution；
- migration cost；
- HBM / packaging / power tightness；
- Anchor Buyer commitments；
- seller-assisted financing intensity；
- utilization / monetization；
- China frontier-system closure；
- regulation / interoperability。

## 十、研究纪律

当前正式研究正文遵守以下边界：

- revenue share ≠ wafer share；
- demand share ≠ allocation share；
- contracted / secured MW ≠ energized / utilized load；
- generation GW ≠ IT-GW；
- system spec × hypothetical deployment count ≠ actual shipment；
- institutional forecast ≠ company actual；
- guidance ≠ actual；
- conventional memory capability ≠ HBM-class frontier closure；
- supplier-assisted financing ≠ independently financed end demand。
